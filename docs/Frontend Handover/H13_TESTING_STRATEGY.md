# H13 — Testing Strategy

## Unit (Vitest + RTL)
- Pure functions: money formatting, scope comparison, state-derived flags, query-key builders.
- Component logic: form validation, permission gating, loading/empty/error states.

## Integration (Vitest + MSW)
- MSW handlers mirror Appendix A; generated by OpenAPI types.
- Cover every workflow in H05 end-to-end with MSW: happy path, each error code, invalid
  states, empty/zero results, pagination, keyset cursor, raw-blob export, multipart upload
  with malware scan polling, CSRF rotation after login, idempotency-replay.
- Auth flows: login success/failure, session-expiry redirect, bootstrap, forgot/reset/change
  password, mustChangePassword redirect.

## E2E (Playwright)
- Smoke suite against local backend: login → create draft → edit → submit → (second user)
  approve/reject/forward/revert → dashboard/register/export → document upload → notifications.
- Bootstrap flow against a fresh database (CI ephemeral).
- Accessibility scan (axe-core) on every screen.

## Contract drift
- CI fetches `/v3/api-docs` and diffs against the committed `schema.d.ts`; fails on breaking
  change (new required fields, renamed endpoints, missing IDs in H09/H10/Appendix A).
- D-09 permission seed test (`SeededRolePermissionsD09Test`) asserts every role with
  view-scope/view-all holds view-own after V28; runs against a Testcontainers Postgres
  (exercises V28 + the self-verification DO block in-VM). Passes on CI at `38cedbc`.
- Idempotency concurrency tests (`IntegrationApiTest.concurrentSameKeyCollapses`,
  `IdempotencyApiTest.concurrentDuplicateExecutesOnce`, `IdempotencyApiTest.concurrentInProgressReturns409`)
  exercise the REQUIRES_NEW collision path; they pass after the `92c7d5a` fix.
